# PIANO LEARNING V6.0.0

## 本版定位
「經典教材型」第一個可操作網站版本。

## 主畫面
- 正規鋼琴大譜表概念：右手高音譜表 + 左手低音譜表
- 練習時採連續橫向譜面，由右往左移動
- 固定演奏判定線
- 底部鋼琴鍵盤
- 音符抵達判定線時，對應琴鍵同步亮起
- 樂譜、節拍器、BPM 使用同一時間基準

## 抽屜
1. 歌曲・分類
2. 拍照歌譜
3. 參數設定
4. 練習

## 拍照轉譜
V6.0.0 已完成 UI、照片載入、網站內存檔與 OMR→MusicXML 接口位置。
真正 OMR 辨識尚未接入本預覽版，避免把示意辨識當正式結果。

## 鋼琴音源
- 網站自有路徑：assets/audio/piano/
- 本版內附 48kHz / 24-bit stereo lossless WAV 示範鋼琴取樣
- 正式最高音質建議後續換成有授權的真實三角鋼琴 multi-sample，多力度層 + release + pedal resonance
