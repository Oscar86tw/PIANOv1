# PIANO LEARNING V6.2.2

## V6.2.2 練習畫面修正

### 左右手分區
練習樂譜畫面正式切成上下兩個獨立區塊：
- 上半部：右手
- 下半部：左手

兩區有明確中央分隔線，不再讓兩組五線譜擠在一起。

### 五線譜與音符放大
相對 V6.2.1：
- 五線譜線距約放大 1.5 倍
- 音符頭同步放大
- 符桿同步放大
- Beam 同步放大
- 譜號、拍號、升降記號同步放大

### Beam / 橫條
使用者提供的 Canon 參考圖中，左手八分音符琶音群組採「符桿向上、Beam 在音符上方」。
V6.2.2 的 Practice Renderer 對成組八分／十六分音符採同一方向顯示，
避免上一版同一練習畫面有的 Beam 在上、有的在下造成閱讀混亂。

注意：正式出版樂譜在不同聲部與音域中，本來可能出現向上或向下的符桿；
這裡是「練習介面正規化顯示」，優先匹配使用者提供的教材風格。

### 紅色拍點線
- 寬度由 3px 改為 9px
- 約為 V6.2.1 的 3 倍
- 預備四拍仍由左側移到正式拍點

### 拍子聲音
參數設定增加清楚的：
- 拍子聲音：開 / 關
- 拍子音量
- 預設開啟

節拍器仍直接使用 Transport 的 AudioContext Master Clock，
與樂譜移動共用同一拍點時間。
